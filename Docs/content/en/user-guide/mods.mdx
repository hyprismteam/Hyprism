# Mods

Mods belong to one [instance](/user-guide/instances-profiles-mods). Open the instance before managing its content so the game version and destination are unambiguous

## Discover mods

1. Open an installed instance
2. Select **Discover mods**
3. Search by name and adjust category or sorting when needed
4. Open a result to inspect its files, supported versions, screenshots, author, and description
5. Select a compatible file and install it

You can also select several compatible results and use the bulk installation action. Incompatible files are disabled for the current game version

Hyprism retrieves catalog data and files from [CurseForge](https://www.curseforge.com/hytale). The project page link opens the original listing in your browser

## Import local files

Open **Installed mods**, then use the import action or drop `.jar` and `.zip` files onto the list. Hyprism copies accepted files into the selected instance

Only import mods from sources you trust. A mod executes with the permissions of the game process

## Enable, disable, and delete

- Use the switch on a row to enable or disable one mod
- Select several rows for bulk enable, disable, or delete actions
- Deleting a mod removes its file from the instance after confirmation
- Search filters the installed list by mod name or author

Disabled files stay in the instance so they can be enabled again without downloading

## Update mods

Select **Check for updates** to compare installed CurseForge files with compatible releases. When updates are available, update one mod or use **Update all**

Back up the instance before a major mod change when a world depends on that mod. Hyprism does not guarantee save compatibility between mod versions
