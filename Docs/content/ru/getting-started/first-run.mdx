# Первый запуск

Для запуска Hytale нужен один профиль игрока и один экземпляр игры

Если старая версия хранила данные в каталоге `HyPrism`, при запуске лаунчер автоматически перенесет их в `Hyprism`. Если существуют оба каталога, порядок их объединения описан на странице [Данные и кэш](/architecture/data-and-cache).

## 1. Выберите язык интерфейса

Откройте **Настройки → Общие → Язык интерфейса**. Лаунчер применит новый язык сразу

## 2. Создайте профиль

Откройте **Профили**, нажмите **Добавить** и выберите тип профиля

- **Официальный аккаунт Hytale** открывает страницу входа Hytale в системном браузере и требует учетную запись с купленной Hytale
- **Оффлайн-профиль** создает локальную личность с именем от 3 до 16 латинских букв, цифр, дефисов или символов подчеркивания

Режимы аутентификации и управление профилями описаны на странице [Профили](/user-guide/profiles)

## 3. Создайте экземпляр

Откройте **Экземпляры**, нажмите **Новый экземпляр**, выберите ветку и версию, затем подтвердите создание. На этом шаге файлы игры еще не загружаются

Установка, запуск и удаление описаны на странице [Экземпляры](/user-guide/instances-profiles-mods)

## 4. Проверьте параметры запуска

Настройки по умолчанию подходят большинству систем. Перед первой загрузкой при необходимости проверьте следующие разделы

- **Настройки → Java** для выбора своей Java или ограничения памяти
- **Настройки → Общие → Используемая видеокарта** на системах с несколькими видеокартами
- **Настройки → Загрузки**, если вы намеренно используете стороннее зеркало
- **Настройки → Сеть** для выбора сетевой или автономной сессии офлайн-профиля

## 5. Установите и запустите игру

Откройте экземпляр и нажмите **Запустить**. Hyprism загрузит выбранную версию, подготовит среду выполнения и запустит игру после успешной установки

После создания экземпляр остается доступен на странице [Экземпляры](/user-guide/instances-profiles-mods)

:::tip
Не закрывайте лаунчер во время первой установки. Наведите указатель на активное действие экземпляра, чтобы при необходимости появилась кнопка **Отмена**
:::
