# Сайт документации

Документация использует Docusaurus 3 в каталоге `Docs`. Нужны Node.js 22 и npm

## Локальный запуск

```bash
cd Docs
npm ci
npm run dev
```

Откройте [локальную документацию](http://localhost:3000/launcher/docs/). Разработка и GitHub Pages используют одинаковый базовый путь `/launcher/docs`

## Контент и языки

Английские страницы находятся в `content/en`, русские в `content/ru`. Маршруты деревьев должны совпадать. Переключатель меняет язык по тому же публичному URL и сохраняет выбор в браузере

`plugins/localized-docs` находит MDX, извлекает текст для поиска, читает навигацию и отклоняет отсутствующие переводы. Строки интерфейса сайта находятся в `src/i18n.ts`

Для разделов, на которые ссылаются другие страницы, задавайте одинаковые явные ID в обоих языках

```md
## Загрузки {/* #downloads */}
```

Ссылки документации используют маршруты вроде `/getting-started/...`; компонент MDX добавляет базовый путь публикации. Ссылки на исходники задаются относительно MDX-файла, например `../../../../Sources/Hyprism.Core/Models/Config.cs`. Плагин проверяет наличие цели и при сборке преобразует путь в ссылку на исходник в GitHub

## Навигация и иконки

`_meta.ts` каждого каталога задает порядок и подписи. Поле `icon` относится к этой категории, а не к дочерним категориям

```typescript
export default {
  icon: 'code-blocks',
  building: 'Сборка',
  testing: 'Тестирование',
  packaging: 'Упаковка и релизы'
}
```

Пять основных категорий используют локальные SVG из Google Material Symbols Rounded. Набор хранится в `MaterialSymbol.tsx` и не требует загрузки внешнего шрифта

## Бренд и тема

`src/css/custom.css` отвечает за темную визуальную систему Hyprism Launcher: шапку, оболочку документации, главную страницу, примеры кода, адаптивную компоновку и футер. Тема использует локальные файлы Google Sans и JetBrains Mono из `static/fonts` и знак лаунчера из `static/img/hyprism-logo.svg`

`src/theme/Footer/index.tsx` отвечает за крупный призыв перейти на сайт команды и ссылки под ним. При изменении футера обновляйте английские и русские строки в `src/i18n.ts`

`DocsSidebar.tsx` отображает дерево категорий в левой колонке на широких экранах. В компактном режиме `Navbar/MobileSidebar/index.tsx` помещает поле поиска и то же дерево в панель на всю область экрана под существующей шапкой. Панель использует тот же принцип раскрытия, что и переключатель языка, закрывается по клику вне, Escape или переходу и не создаёт вторую шапку

## Примеры и текст

Следуйте `AGENTS.md`: пользовательские инструкции описывают действия и результат, технические страницы описывают ответственность, контракты и ограничения сопровождения

Каждый кодовый блок должен иметь язык: `bash`, `powershell`, `csharp`, `json`, `xml`, `typescript` или `text`. Условия и результат примера описываются вне блока

`LocalizedDocPage` оборачивает содержимое в `MDXContent` Docusaurus. Это подключает заголовки, ссылки, примечания и кодовые блоки темы. Грамматики Prism настраиваются в `docusaurus.config.ts`

## Скриншоты {/* #screenshots */}

Снимки рендерят настоящие представления Avalonia с фиксированными примерами профилей, экземпляров и ответов сервисов. Они показывают интерфейс, а не живую игровую сессию или текущие внешние новости

Из корня репозитория

```bash
HYPRISM_DOCS_SCREENSHOTS="$PWD/Docs/static/img/user" \
  dotnet test Tests/Hyprism.Desktop.Tests/Hyprism.Desktop.Tests.csproj \
  --filter FullyQualifiedName~DocumentationScreenshotTests
```

Тест записывает PNG на двух языках в `Docs/static/img/user/en` и `ru`. Без переменной каталога съемка пропускается. Представления рендерятся с двойной плотностью пикселей, без увеличения готового изображения. Для диалогов снимается только нужный реальный элемент управления

Используйте изображение нужного языка, содержательный альтернативный текст и ссылку на оригинал для просмотра в полном размере. Обрезайте диалоги и списки, если остальное окно не помогает. Проверяйте каждый снимок на отсутствующие данные, обрезанные элементы и незавершенные переходы

## Проверка и экспорт

```bash
cd Docs
npm ci
npm run check
PAGES_BASE_PATH=/launcher/docs npm run build
```

`npm run check` запускает тесты валидатора, проверяет текст, паритет языков, кодовые блоки, изображения, маршруты, двуязычные якоря, ссылки на исходники и документацию контрактов Core, затем запускает TypeScript. Статический экспорт записывается в `Docs/out/launcher/docs`, чтобы опубликованный сайт был доступен по адресу `/launcher/docs/`

В готовом сайте проверьте подсветку C#, shell, JSON и XML, переключение языка, ссылки разделов, иконки и узкую компоновку

## Публикация

`docs-pages.yml` проверяет и публикует экспорт. В **Settings → Pages** репозитория источником должны быть **GitHub Actions**

Опубликованный вход: [сайт документации Hyprism](https://hyprism.org/launcher/docs/). Не добавляйте в коммит `out`, `.docusaurus`, `node_modules` и старые результаты `.next`
