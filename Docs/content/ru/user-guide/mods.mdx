# Моды

Моды принадлежат одному [экземпляру](/user-guide/instances-profiles-mods). Перед управлением содержимым откройте нужный экземпляр, чтобы версия игры и каталог назначения были однозначны.

## Поиск модов

1. Откройте установленный экземпляр.
2. Выберите **Найти моды**.
3. Выберите **CurseForge** или **Modifold** в переключателе источника. Введите минимум четыре символа в строку поиска над фильтрами, затем нажмите **Enter** или значок поиска, который появится внутри поля. При необходимости выберите категорию и порядок сортировки.
4. Выберите результат, чтобы открыть отдельную страницу обзора и проверить файлы, поддерживаемые версии, скриншоты и автора.
5. Выберите совместимый файл и установите его либо нажмите **Назад**, чтобы вернуться в каталог.

Можно выбрать несколько совместимых результатов и нажать **Установить** справа в верхней панели. Несовместимые с текущей версией игры файлы недоступны.

После подтверждения установки из каталога Hyprism открывает обзор экземпляра. Карточка **Найти моды** недоступна, пока её бейдж показывает прогресс. Нажмите бейдж, чтобы выбрать **Отмена**. Отмена или ошибка загрузки откатывает весь пакет, включая загруженные зависимости; файлы и настройки модов, установленных до операции, сохраняются.

Hyprism получает каталог и файлы с [CurseForge](https://www.curseforge.com/hytale) или [Modifold](https://modifold.com/). Кнопка страницы проекта открывает запись на выбранной площадке в браузере. Для поиска и загрузки с Modifold в Hyprism не нужны ключ API или учётная запись. Ключ API CurseForge Hyprism получает автоматически при запуске. Зависимости модов Modifold автоматически не загружаются: проверьте требования мода перед установкой.

## Управление установленными модами

1. Откройте установленный экземпляр и выберите **Установленные моды**.
2. Введите имя мода или автора в поле поиска сверху. Список обновляется по мере ввода. Нажмите **Esc** или щёлкните вне поля, чтобы завершить ввод и сохранить запрос.
3. Кнопки рядом с поиском позволяют **Добавить мод** или **Проверить обновления**. Наведите указатель на значок, чтобы увидеть название действия. Список обновляется автоматически после импорта, установки, удаления и обновления модов.
4. Выберите флажки рядом с модами, затем откройте меню с тремя точками справа в верхней панели, чтобы включить, отключить, удалить выбранные моды или очистить выбор.

Каждая строка показывает имя мода, установленную версию, автора и тип выпуска. Переключатель и кнопка удаления находятся справа; доступные обновления отображаются рядом с автором. Бейджи релиза зелёные, бета-версии фиолетовые, а альфа-версии жёлтые.

Чтобы удалить один мод, нажмите значок корзины в его строке. Проверьте имя мода в оверлее подтверждения и нажмите **Удалить**, чтобы убрать его файл из экземпляра, или **Отмена**, чтобы сохранить его.

## Импорт локальных файлов

Откройте **Установленные моды** и используйте импорт либо перетащите файлы `.jar` и `.zip` в список. Hyprism скопирует подходящие файлы в выбранный экземпляр.

Импортируйте моды только из доверенных источников. Мод выполняется с правами процесса игры.

## Включение, отключение и удаление

- Переключатель в строке включает или отключает один мод.
- Выберите несколько строк и откройте меню с тремя точками для массового включения, отключения или удаления. Массовое удаление убирает выбранные файлы из экземпляра.
- Используйте значок корзины в строке, чтобы удалить один мод после подтверждения.
- Поиск фильтрует установленный список по имени мода или автору.

Отключенные файлы остаются в экземпляре, поэтому их можно вернуть без повторной загрузки.

## Обновление модов

Нажмите **Проверить обновления**, чтобы сравнить установленные файлы CurseForge с совместимыми релизами. При наличии обновлений установите их по одному или используйте **Обновить все**. Проверка не включает моды Modifold.

Перед крупным обновлением модов сохраните копию экземпляра, если мир зависит от них. Hyprism не гарантирует совместимость сохранений между версиями модов.
