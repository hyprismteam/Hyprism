# Local Node

`Hyprism.LocalNode` является отдельным executable, который поставляется вместе с Hyprism Launcher. Во время автономных сессий локальных профилей лаунчер запускает его отдельным процессом. Он слушает только `127.0.0.1`, поэтому запросам клиента не нужны DNS и удаленный сервер аутентификации

## Управляемый жизненный цикл

`LocalNodeServiceFactory` выделяет свободный порт `8443 to 9999` и отдельный каталог `LocalNode/Sessions/<session-id>` для каждого запуска. Аккаунты и сертификаты общие для всех сессий

1. `GameLauncher` создает ноду и передает каталог экземпляра
2. `LocalNodeHost` подготавливает сертификаты и запускает `Hyprism.LocalNode` отдельным процессом
3. Лаунчер ожидает HTTPS health и создает локальную сессию
4. Подготовка клиента перенаправляет сервисы и передает доверие сертификату
5. После старта игры лаунчер привязывает ее PID к ноде
6. Нода работает до завершения игры, даже если Desktop закрыт

До привязки управляемая нода следует за процессом лаунчера. Запросы жизненного цикла требуют уникальный секрет `X-Hyprism-Control`

## HTTP API

| Группа | Маршруты и поведение |
| --- | --- |
| Готовность и ключи | `/health`, `/.well-known/jwks.json`, `/jwks.json` |
| Создание сессии | `POST /v1/sessions`, `/game-session`, `/game-session/new` |
| Срок жизни сессии | `/game-session/child`, `/game-session/refresh`, `DELETE /game-session` |
| Обмен с сервером | `/game-session/authorize`, `/server-join/auth-grant`, `/server-join/auth-token`, `/game-session/exchange`, `/validate`, `/server/auto-auth` |
| Аккаунт и профиль | `/my-account/game-profile`, `/my-account/get-profiles`, `/my-account/get-launcher-data`, `/profile/uuid/{uuid}`, `/profile/username/{username}` |
| Персонаж | `/my-account/skin`, `/my-account/cosmetics`, `/account-data/skin/{uuid}`, `/player-skins` и вложенные маршруты |
| Жизненный цикл | `POST /v1/lifecycle/attach`, `POST /v1/lifecycle/stop` для управляемых процессов |
| Совместимость | Конфигурация, телеметрия, presence, пустые социальные ответы и поиск серверов |

Хост отклоняет неожиданные заголовки Host и ограничивает тело запроса до 2 МиБ. Маршруты совместимости не предоставляют общий граф друзей, приглашения, облачную синхронизацию, NAT traversal или публичное обнаружение

Реализация маршрутов находится в `Sources/Hyprism.LocalNode/LocalNodeApplication.cs`, тесты в `Tests/Hyprism.LocalNode.Tests/LocalNodeHostTests.cs`

## Токены и состояние персонажа

Выбранный локальный профиль получает временный ключ Ed25519. Передача identity включает приватный JWK для DualAuth. JWKS, grant и access token содержат только публичный ключ

Авторизация отдельно проверяет Bearer-сессию игрока и личность целевого сервера в теле запроса. Access token привязывается к отпечатку сертификата через `cnf.x5t#S256`. Обновление и дочерние сессии используют тот же ключ профиля

Активный персонаж передается в строковом claim `skin`. Каталог косметики читает установленные предметы из `Assets.zip` экземпляра и использует небольшой резервный каталог, если архив недоступен

## Доверие сертификатам {/* #certificate-trust */}

Общий центр сертификации хранится в `LocalNode/Certificate`. Серверный сертификат действует для IP-адреса, а не конкретного порта

| Платформа | Настройка доверия |
| --- | --- |
| Windows | Добавление центра в корневое хранилище текущего пользователя при отсутствии |
| Linux | Передача объединенного CA bundle процессу игры |
| macOS | Регистрация центра в admin trust settings с возможным системным запросом и передача CA bundle |
| Java на всех платформах | Отдельное хранилище PKCS#12 |

Серверный сертификат заменяется при повреждении, другом центре, отсутствии IP-адреса или остатке срока менее семи дней. Центр действует десять лет, если не поврежден. Отмена запроса доверия macOS прерывает запуск

Приватные `.pfx` принадлежат локальному состоянию и не должны распространяться вместе со скриншотами, логами или фикстурами

## Автономная разработка

Автономный executable Local Node по умолчанию использует порт `8443` и каталог `LocalNodeData` рядом с executable. Пример из корня репозитория с отдельным каталогом

```bash
hyprism_node_data="$(mktemp -d)"
dotnet run --project Sources/Hyprism.LocalNode/Hyprism.LocalNode.csproj -- \
  --data-directory "$hyprism_node_data" \
  --port 8443
```

Автономный запуск также может настроить системное доверие. Для тестирования предпочтителен набор Local Node: он отключает изменения системного доверия и закрепляет созданный сертификат

| Параметр | Назначение |
| --- | --- |
| `--data-directory` | Каталог runtime-состояния |
| `--hostname` | Только `127.0.0.1` |
| `--port` | Порт отдельного запуска от 1024 до 65535 |
| `--assets-path` | Установленный `Assets.zip` для каталога косметики |
| `--certificate-directory` | Повторное использование центра и серверного сертификата |
| `--account-data-directory` | Общее хранилище аккаунтов и скинов |
| `--log-file` | Путь ограниченного по размеру лога |
| `--request-journal` | Путь журнала неизвестных запросов |
| `--owner-pid`, `--control-secret` | Пара управления жизненным циклом, задаются вместе |

Параметры передаются парами `--name value`. Неизвестные и повторяющиеся параметры отклоняются

## Диагностика и совместимость

Управляемые логи используют [каталог сессии лаунчера](/architecture/data-and-cache). Диагностика аутентификации не сохраняет заголовки, значения токенов и тела запросов

Протокол следует открытой [реализации hytale-auth-server](https://github.com/sanasol/hytale-auth-server). Тесты покрывают HTTPS, хранение аккаунтов, токены, сертификаты, процессы и смену патчей клиента; новую проприетарную сборку Hytale нужно дополнительно проверять реальным запуском
