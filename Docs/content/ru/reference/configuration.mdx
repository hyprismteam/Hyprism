# Конфигурация

`JsonConfigStore` читает и сохраняет `Config.json` в [каталоге приложения](/architecture/data-and-cache). Свойства JSON используют PascalCase, чтение нечувствительно к регистру

Перед ручным редактированием закройте лаунчер и сохраните остальные поля. Пример показывает часть настроек, а не полную замену файла

```json
{
  "Language": "ru-RU",
  "CloseAfterLaunch": false,
  "UseCustomJava": false,
  "JavaArguments": "-Xms2G -Xmx4G",
  "GpuPreference": "auto",
  "OnlineMode": false
}
```

## Выбор и аутентификация

| Ключ | По умолчанию | Назначение |
| --- | --- | --- |
| `Version` | `2.0.0` | Версия схемы конфигурации, не релиза |
| `SelectedInstanceId` | пусто | ID текущего экземпляра |
| `SelectedProfileId` | пусто | ID активного профиля |
| `OnlineMode` | `true` | Сетевая аутентификация локальных профилей |
| `AuthDomain` | `sessions.sanasol.ws` | Сервис сессий локальных профилей |
| `AuthServers` | `[]` | Добавленные пользователем серверы авторизации в настройках сети |
| `CurseForgeKey` | пусто | API-ключ, подготавливаемый при инициализации |

Официальный профиль всегда использует официальную аутентификацию и не показывает редактор Auth Server. Для неофициального профиля список появляется только при включенном сетевом режиме. Встроенный адрес `sessions.sanasol.ws` всегда остается в списке; `AuthServers` хранит дополнительные пользовательские записи, а `AuthDomain` выбранное значение. Desktop проверяет каждый сервер из списка через игровой API создания сессии и не сохраняет результат проверки в конфигурации. Local Node выбирает свободный порт `8443–9999` на `127.0.0.1`; адрес и порт конкретного запуска в файле не хранятся

## Параметры запуска

| Ключ | По умолчанию | Назначение |
| --- | --- | --- |
| `CloseAfterLaunch` | `false` | Закрытие Desktop после успешного запуска |
| `UseCustomJava` | `false` | Использование `CustomJavaPath` |
| `CustomJavaPath` | пусто | Путь к исполняемому файлу Java |
| `JavaArguments` | пусто | Аргументы JVM и управляемые UI параметры кучи |
| `GpuPreference` | `dedicated` | Автоматический выбор, тип или ключ адаптера |
| `GameEnvironmentVariables` | пусто | Присваивания `KEY=VALUE`, разделенные переносом |

GPU принимает `auto`, старые типы `dedicated` и `integrated`, ключ `pci:<id>` при наличии или имя адаптера. Платформенные реализации переводят выбор в поддерживаемые параметры запуска

## Интерфейс и хранение

| Ключ | По умолчанию | Назначение |
| --- | --- | --- |
| `Language` | `en-US` | Культура интерфейса |
| `MusicEnabled` | `true` | Сохраненное предпочтение фоновой музыки |
| `ShowDiscordAnnouncements` | `true` | Сохраненное предпочтение объявлений |
| `DismissedAnnouncementIds` | `[]` | ID скрытых объявлений |
| `DisableNews` | `false` | Предпочтение отключения новостей |
| `InstanceDirectory` | пусто | Стандартный или пользовательский корень экземпляров |
| `ShowAlphaMods` | `false` | Показ alpha-релизов модов |
| `LastExportPath` | пусто | Последний каталог экспорта модов |
| `HasCompletedOnboarding` | `false` | Состояние совместимости для первого знакомства |

Наличие сохраненного поля не означает готовый сценарий Desktop. Первоначальное знакомство и просмотр логов экземпляра пока не завершены

## Совместимость

Имена, UUID и сессии профилей принадлежат `Profiles`, а не `Config.json`. При загрузке старых данных поля `Nick`, `UUID`, `Profiles` и `ActiveProfileIndex` переносятся в хранилище профилей

`Instances`, `VersionType` и `SelectedVersion` оставлены для совместимости. `PreferredMirror` устарел и игнорируется, источник выбирается автоматически

## Переменные среды

| Переменная | Область действия |
| --- | --- |
| `HYPRISM_DATA` | Существующий каталог всех данных приложения |
| `XDG_DATA_HOME` | Корень данных Linux без `HYPRISM_DATA` |
| `HYPRISM_WIN32_COMPOSITION` | Диагностика рендеринга Windows, см. [производительность](/development/avalonia-performance) |
| `HYPRISM_DOCS_SCREENSHOTS` | Каталог для явного запуска [снятия скриншотов](/development/documentation#screenshots) |

При запуске дочерние процессы также получают переменные Java, DualAuth, GPU и сертификатов. Эти значения не являются отдельными настройками лаунчера
