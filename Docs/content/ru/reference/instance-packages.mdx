# Пакеты экземпляров

Hyprism экспортирует экземпляр в виде JSON-манифеста с метаданными или ZIP-архива с выбранными файлами. Визард экземпляров импортирует оба формата. Пользовательские шаги описаны в разделе [Экземпляры](/user-guide/instances-profiles-mods).

## Состав и структура

| Тип | Включённые файлы |
| --- | --- |
| Сборка | Все файлы экземпляра, включая игру, моды, миры и остальные пользовательские данные. |
| Модпак | Файлы из `UserData/Mods/`, включая манифест модов. |
| Игра | Файлы экземпляра вне `UserData/` и `Client/mods/`. |

Каждый экспорт JSON содержит поля `SchemaVersion`, `Kind`, `Instance`, `Files` и `Mods`. Значение `SchemaVersion` равно `1`. Поле `Kind` принимает `Build`, `Modpack` или `Game`. Поле `Instance` содержит исходный `InstanceMeta`, `Files` перечисляет пути относительно корня экземпляра и размеры файлов в байтах, а `Mods` содержит метаданные установленных модов, когда моды включены. Содержимое файлов в JSON отсутствует.

Каждый экспорт ZIP содержит `HyprismExport.json` с тем же манифестом, `Meta.json` для импорта экземпляра и выбранные файлы по путям относительно экземпляра. Символические ссылки исключены. Экспорт пишет во временный файл рядом с местом назначения и заменяет файл назначения только после завершения. При отмене временный файл удаляется.

`InstancePackageService.ExportAsync` принимает необязательный обработчик прогресса `IProgress<int>`. При экспорте ZIP он сообщает процент скопированных байтов выбранных исходных файлов, не выше 99 до завершения архива и замены файла назначения. Экспорт JSON сообщает 0 перед записью и 100 после замены. Эти значения не показывают размер сжатого архива.

Импорт JSON создаёт новый неустановленный экземпляр с исходными именем, веткой, версией, названием версии и заметками. Указанные файлы не загружаются и не восстанавливаются. При экспорте ZIP в `Meta.json` назначается новый ID экземпляра, а манифест сохраняет исходный ID. Импорт ZIP распаковывает архив, назначает другой ID при совпадении и регистрирует экземпляр.

При отмене распаковки ZIP временный каталог удаляется до переноса файлов в экземпляр.

Реализация находится в [InstancePackageService](../../../../Sources/Hyprism.Core/Game/Instances/InstancePackageService.cs) и [InstanceRepository](../../../../Sources/Hyprism.Core/Game/Instances/InstanceRepository.cs).
