# Пакеты экземпляров

Hyprism экспортирует описание сборки или игры в виде шаблона JSON либо упаковывает выбранные файлы экземпляра в ZIP-архив. Визард экземпляров импортирует оба формата. Пользовательские шаги описаны в разделе [Экземпляры](/user-guide/instances-profiles-mods).

## Состав и структура

| Тип | Включённые файлы |
| --- | --- |
| Сборка | Все файлы экземпляра, включая игру, моды, миры и остальные пользовательские данные. |
| Модпак | Файлы из `UserData/Mods/`, включая манифест модов. |
| Игра | Файлы экземпляра вне `UserData/` и `Client/mods/`. |

Сборку или игру можно экспортировать как шаблон JSON со значением `SchemaVersion` равным `2` и объектом `Instance`, который содержит имя, ветку, номер сборки и необязательное название версии. Шаблон сборки также содержит заметки, а шаблон игры их не включает. Путей к файлам, метаданных модов и содержимого файлов в шаблоне нет. Экспорт модпака требует ZIP. Старые JSON-манифесты схемы `1` по-прежнему импортируются; списки файлов и модов при импорте игнорируются.

Шаблон имеет следующий вид. Поля `VersionName` и `Notes` отсутствуют, если их значения не заданы.

```json
{
  "SchemaVersion": 2,
  "Instance": {
    "Name": "Мой экземпляр",
    "Branch": "release",
    "Version": 72,
    "VersionName": "Предрелиз",
    "Notes": "Мои настройки"
  }
}
```

Каждый экспорт ZIP содержит манифест `HyprismExport.json` схемы `1` с полями `Kind`, исходным `InstanceMeta`, путями и размерами выбранных файлов и метаданными установленных модов, если они включены. Архив также содержит `Meta.json` для импорта экземпляра и выбранные файлы по путям относительно экземпляра. Символические ссылки исключены. Экспорт пишет во временный файл рядом с местом назначения и заменяет файл назначения только после завершения. При отмене временный файл удаляется.

`InstancePackageService.ExportAsync` принимает необязательный обработчик прогресса `IProgress<int>`. При экспорте ZIP он сообщает процент скопированных байтов выбранных исходных файлов, не выше 99 до завершения архива и замены файла назначения. Экспорт JSON сообщает 0 перед записью и 100 после замены. Эти значения не показывают размер сжатого архива.

Импорт JSON требует настроенного источника загрузки и создаёт новый неустановленный экземпляр с исходными именем, веткой, версией, названием версии и заметками. Файлы не загружаются и не восстанавливаются. При экспорте ZIP в `Meta.json` назначается новый ID экземпляра, а манифест сохраняет исходный ID. Импорт ZIP распаковывает архив, назначает другой ID при совпадении и регистрирует экземпляр.

При отмене распаковки ZIP временный каталог удаляется до переноса файлов в экземпляр.

Реализация находится в [InstancePackageService](../../../../Sources/Hyprism.Core/Game/Instances/InstancePackageService.cs) и [InstanceRepository](../../../../Sources/Hyprism.Core/Game/Instances/InstanceRepository.cs).
